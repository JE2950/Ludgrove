# Ludgrove Map

A Minecraft-style map of Ludgrove School that you can walk round or fly over. The layout follows the aerial photo of the school, and the buildings and rooms follow the 360° tour panoramas.

Open `index.html` in a browser, or serve the folder with GitHub Pages. The page is a single file with no build step.

## Controls

- `W` `A` `S` `D` move, mouse to look
- `Space` jump (flying: up), `Shift` run (flying: down)
- `F` switch between walking and flying
- `M` open the map, then click a place to go there
- `N` change the season: spring, summer, autumn or winter
- `P` change the sport on the pitches: football, rugby or cricket
- `Esc` pause

On a phone or tablet, move with the left stick and drag to look.

The map opens on today's season. The pitches start on football from September to December, rugby from January to March and cricket from April to August.

## Places

Front of House, the Study, the Dining Hall, the Dormitories, the classrooms, the Games Room, the Quad, the Library, Music, the Theatre, the Chapel, the Swimming Pool, the Fives courts, the Sports Hall, the Tennis Courts, the Exploration Centre (Art Room, Ceramics and CDT), the Monkey House, the Top Lawn, the Camps, Chapel Ground, and the pavilions and main pitches.

Built on the voxel engine from the Fuga Romana escape room. Not to scale.
